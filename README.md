# [FLIGHT] 프로모션 페이지 제작

항공 프로모션 요청 시트(Google Sheet)를 읽어 실제 고객 노출용 **프로모션 페이지**를 자동으로 조립하고, 화면에서 바로 문구·이미지·순서·테마를 편집한 뒤 섹션별 JPG(또는 ZIP)로 내보내는 웹 도구입니다.

- **라이브(live)**: 라이브 일정, 라이브 혜택, 퀴즈 경품, "특가 노선 보러가기" CTA 중심
- **기획전(plan)**: 라이브 관련 섹션 숨김. 프로모션 기간, 구매 혜택, 강조 노선, 전체 노선 중심

---

## 1. 실행 방법

```bash
cd app
npm install
npm run dev        # http://localhost:5173
```

다른 명령어:
```bash
npm run build      # 타입체크 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 미리보기
npm run typecheck  # 타입체크만
```

## 2. 화면 구성

- **좌측 (섹션 목록)**: 드래그로 섹션 순서 변경, 👁/🚫로 숨기기, ⬇로 섹션 1개만 저장, 하단에 필수 항목 검증 결과 표시
- **중앙 (미리보기)**: 실제 프로모션 페이지가 모바일/PC 프레임으로 렌더링되는 캡처 영역
- **우측 (설정 패널)**: 시트 불러오기, 선택한 섹션의 이미지·옵션 편집, 스타일 테마, 전체 저장

상단 툴바에서 **Live ON/OFF**(라이브·기획전 전환), **📱 모바일 / 🖥 PC** 전환, **🖼 이미지 자동 채우기**(Unsplash 이미지 켜기/끄기), **⬇ 전체 저장**을 할 수 있습니다.

## 3. 프로모션 데이터 불러오기 (구글 시트)

우측 패널 상단 "📄 구글 시트"에서:

1. 시트를 **공유 → 링크가 있는 모든 사용자(뷰어)**로 공개
2. 시트 링크를 붙여넣고 🔄 클릭
3. 여러 탭이 있으면 드롭다운에서 선택 → 자동 재로딩

불러오기 경로는 두 가지입니다.
- **구글 계정 연결(OAuth)**: 비공개 시트도 가능. 최초 1회 로그인 필요(`고급 설정`에서 OAuth 클라이언트 ID 입력, 아래 "로컬 개발 환경 설정" 참고)
- **공개 시트 직접 불러오기**: OAuth 없이 공개(CSV) 링크만으로 로드. CORS로 막히면 `프록시로 불러오기` 체크(로컬 개발 시 Vite가 자동 처리, 운영 배포 시 `npm run proxy`로 별도 프록시 서버 필요)

### 시트 작성 규칙
- `■ 섹션명` 행으로 섹션 구분 (`프로모션 개요`, `항공사 강조`, `라이브 혜택`, `라이브 경품`, `구매 혜택`, `강조 노선`, `전체 노선` 등)
- `[항목명]` 대괄호 헤더로 컬럼 인식 (헤더가 1개면 key-value, 2개 이상이면 표)
- 날짜는 `2026-07-20` / `2026.7.20` 또는 이미 `26년 07월 20일` 형식 모두 인식되어 `YY년 MM월 DD일 (요일)` 형태로 통일됩니다
- **항공사 강조** 표는 `[메인 문구]`, `[서브 문구]` 컬럼 값만 사용합니다(다른 컬럼명으로 대체되지 않음 — 반드시 이 헤더명을 써주세요)
- **라이브 경품** 표는 `[수량]` 컬럼 값을 서브 문구로 고정 사용합니다(숫자만 있으면 `· N명` 형태로 자동 정리)
- **전체 노선** 표는 `출발지 / 권역 / 도시 / 공항코드 / 가격` 컬럼을 유연하게 매칭해 트리로 조립합니다
- 공항 코드는 자동으로 한국어 도시명으로 변환됩니다(목록에 없는 코드는 아래 4-5 참고)

## 4. 미리보기에서 편집하기

- **텍스트**: 미리보기의 문구를 그냥 클릭하면 바로 수정 가능(별도 저장 버튼 없이 포커스 아웃 시 저장)
- **이미지**: 노선 카드에 마우스를 올리면 나오는 📷 아이콘으로 개별 이미지 교체, ↺로 자동 이미지로 복원
- **KV 스타일 / 항공사 로고·기체·배경 이미지**: 좌측에서 "메인 비주얼" 섹션 선택 후 우측 패널에서 업로드
- **스타일 테마**: 우측 패널 하단에서 8가지 색상 중 선택(강조 색상·연한 배경·짙은 색이 전체에 자동 반영)
- **강조 노선 – 출발지 노출**: "강조 노선" 섹션 선택 시 나오는 체크박스로 카드에 `출발지 → 도착지` 전체를 보여줄지, 도착지만 보여줄지 전체 카드에 일괄 적용(텍스트가 넘칠 정도로 길면 자동으로 도착지만 표시하는 안전장치 포함)
- **구매 혜택 – 대표 카드**: 혜택이 홀수 개일 때 카드 우상단 ☆를 눌러 그 카드를 맨 위 가로 전체 폭 카드로 배치 가능
- **섹션 타이틀 새로고침**: 라이브 혜택/구매 혜택/강조 노선 섹션 선택 시 나오는 🔄 버튼으로 랜덤 타이틀 문구를 다시 뽑을 수 있음

## 5. 이미지·에셋 커스터마이징

자동 매칭에 필요한 이미지들은 코드 수정 없이 파일만 넣으면 인식됩니다. 모두 `app/public/assets/` 아래입니다.

| 용도 | 경로 규칙 | 예시 |
|---|---|---|
| 도시 이미지(노선 카드 배경) | `assets/city/{공항코드}.{jpg\|png\|jpeg\|webp}` | `assets/city/NRT.jpg` |
| 항공사 로고 | `assets/airline-logo/{항공사명}.svg` | `assets/airline-logo/티웨이.svg` |
| 항공사 기체 이미지 | `assets/airline-plane/{항공사명}_1.png` (`_2`, `_3` 등 여러 장도 가능, 기본은 `_1`) | `assets/airline-plane/티웨이_1.png` |
| 메인 비주얼 하늘 배경 | `assets/sky/sky_{1~8}.jpg` | `assets/sky/sky_3.jpg` |
| 혜택 아이콘(구매 혜택/항공사 강조) | `assets/promotion-benefit-img/{키}.svg` | `assets/promotion-benefit-img/card.svg` |

> 예: 특정 도시코드에 일치하는 이미지를 로컬에 미리 준비해두고 싶다면 `app/public/assets/city/` 폴더에 해당 공항코드 파일명으로 저장하면 됩니다. 파일이 있으면 Unsplash 자동 검색보다 항상 우선 사용됩니다.

항공사명은 시트의 항공사명에서 공백을 지우고 "항공" 접미사를 유연하게 매칭하므로, 파일명은 시트에 적힌 항공사명과 최대한 동일하게 맞춰주세요.

### 공항 코드 추가
목록에 없는 공항 코드(도시명 매칭 실패)는 `app/src/data/seed.ts`의 `AIRPORTS` 객체에 `코드: '도시명'` 한 줄만 추가하면 됩니다.

## 6. 다운로드(내보내기)

- **섹션 1개만**: 좌측 목록 각 행의 ⬇
- **전체 저장**: 상단 `⬇ 전체 저장` → 모든 노출 섹션을 JPG로 캡처해 ZIP 하나로 다운로드
  - 파일명 규칙: `YYMMDD_항공사명_디바이스.zip` (예: `260720_에어프레미아_MO.zip`)
  - 기준일은 라이브면 라이브 일시, 기획전이면 판매 시작일 기준
- PC/모바일 뷰를 각각 바꿔가며 두 세트를 모두 받아야 합니다.

## 7. 로컬 개발 환경 설정 (구글 OAuth)

`app/.env.example`을 복사해 `app/.env`를 만들고 본인의 Google OAuth 클라이언트 ID를 넣으세요.
```bash
cp app/.env.example app/.env
```
```
VITE_GOOGLE_CLIENT_ID=본인의-클라이언트-ID.apps.googleusercontent.com
```
클라이언트 ID가 없어도 앱 우측 패널의 "고급 설정"에서 직접 입력할 수 있습니다. 다만 Google Cloud Console의 OAuth 클라이언트 "승인된 JavaScript 원본"에 `http://localhost:5173`(또는 배포 도메인)이 등록되어 있어야 로그인이 됩니다.
